# Security / Безопасность

Never post subscription URLs, UUIDs, private keys, passwords, full QR codes,
encrypted backups or raw connection logs in public issues.

For a sensitive report, first open a minimal issue requesting a private contact,
without vulnerability details or credentials. Ordinary bug reports should contain
only redacted diagnostics, the app version, Windows version and reproduction steps.

Не публикуйте ссылки подписок, UUID, приватные ключи, пароли, полные QR-коды,
резервные копии и необработанные логи в публичных обсуждениях.

Для чувствительного сообщения сначала создайте минимальное обращение с просьбой
о приватном контакте, без деталей уязвимости и реквизитов. В обычном отчёте нужны
только очищенная диагностика, версии приложения/Windows и шаги воспроизведения.

FICUS is beta software. Public releases are not a guarantee of leak prevention,
and an obfuscated binary is not a secure place to store server-side secrets.

FICUS находится в бете. Публикация сборки не означает гарантированной защиты от
утечек, а обфусцированный клиент нельзя использовать как тайник для серверных ключей.
